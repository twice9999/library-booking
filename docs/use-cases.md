# 📋 «Читальня» - пользовательские сценарии (use cases)

> См. также: [Описание проекта](description.md) · [README](../README.md)

Формат: **Как** ⟨роль⟩, **я хочу** ⟨действие⟩, **чтобы** ⟨цель⟩.

Всего 60 сценариев. Первые 20 составляют **MVP** и реализованы в текущей версии приложения. Остальные 40 - бэклог для дальнейшего развития.
